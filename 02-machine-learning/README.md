# 🤖 Machine Learning - Clasificación de Flores Iris

## ¿Qué hace este proyecto?
Primer modelo de Machine Learning que predice la especie de una flor
según sus medidas usando un Árbol de Decisión.

## ¿Qué aprendí?
- Qué es Machine Learning y cómo funciona
- Separar datos en X (pistas) y y (respuestas)
- Dividir datos en entrenamiento y prueba con train_test_split
- Entrenar un modelo con DecisionTreeClassifier
- Medir precisión con accuracy_score — resultado: 100% ✅
- Predecir datos nuevos que el modelo nunca había visto

## Tecnologías usadas
- Python
- scikit-learn
- pandas
- Google Colab

## Resultado
El modelo clasificó correctamente las 30 flores de prueba
con una precisión del 100% 🎯
